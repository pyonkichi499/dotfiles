# Codex Agent Configuration

このファイルはCodexエージェントのグローバル設定を定義します。

## 基本設定

- **言語**: 日本語で返信する
- **OS**: macOS (Darwin)
- **シェル**: zsh

## コーディング規約

### 全般

- 簡潔で読みやすいコードを書く
- 冗長なコメントは避け、コードで意図を明確にする
- エラーハンドリングを適切に行う

### Python

- パッケージ管理: `uv` を優先使用
- リンター: `ruff` を使用
- pyenvはレガシー（将来的にuvに移行予定）

## ツール設定

### Git

- コミットメッセージは以下の形式で記載する
  - 日本語
  - conventional commit に従う。具体的には
    - 1行目にはprefix をつけて概要を記載する 
    - 3行目以降に箇条書きで詳細を記載する

## タスク実行プロセス

1. **分析**: タスクを要約し、要件と制約を特定
2. **計画**: 具体的なステップと実行順序を決定
3. **実行**: ステップを一つずつ実行し、進捗を報告
4. **検証**: 結果を確認し、エラーがあれば修正
5. **確認**: 成果物が要件を満たすか評価

## ショートカット

- `/ask`: 相談・質問への多角的な回答（タスク実行なし）
- `/plan`: 作業計画の概説と合意形成
- `/debug`: バグの根本原因分析と仮説検証
- `/cmt`: 適切なコメント追加
- `/log`: 適切なログ追加

## 注意事項

- 不明点は作業前に確認
- 重要な判断は報告して承認を得る
- 問題発生時は即報告し対応策を提案
